# Approved delivery

Implement the user-approved CyberUI Web plan in six sequential milestones:

1. Workspace, vendored reference/assets, seven palettes and two modes, typography,
   CSS tokens, geometry, theme provider.
2. 10 foundation, 16 form, 9 navigation, 11 feedback/overlay, and 6 data components.
3. 13 signature CyberUI components, all progress/panel styles and ASCII modes.
4. Bilingual component catalogue, individual docs/controls/props/code, foundations,
   themes and visual comparison views.
5. Persistent/resettable interactive replica scenes, all 19 reference mappings,
   20 shop appearances, fonts/covers/sleep/menu and reading-log states.
6. Unit, browser, accessibility, responsive, production and independent-consumer
   verification, then update delivery evidence and README.

Public packages: @cyberui/tokens and @cyberui/react (ESM, declarations, explicit CSS).
React Aria owns complex keyboard/focus interactions; Recharts owns standard charts.
No public deployment or registry publishing is part of this delivery.
