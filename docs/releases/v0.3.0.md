# CyberUI v0.3.0

本版本重新设计共享日期选择器，让日历、日期时间和宿主应用使用同一套 CyberUI 主题、字体与直角表面。GitHub Release 提供 `@cyberui/react`、`@cyberui/tokens` 两个 `.tgz` 与 `SHA256SUMS`，组件包包含成品 CSS。源码继续通过 GitHub Registry 分发。

## 日历与日期时间

- DatePicker 提供六周日历、月份与年份切换、今天和清除操作，并区分选中日期、今天与键盘焦点。
- `includeTime` 在同一日历内选择时分。日期值为 `YYYY-MM-DD`，日期时间值为本地 `YYYY-MM-DDTHH:mm`，不隐式转换为 UTC。
- `minValue`、`maxValue`、必填和禁用状态同时约束手输、日历按钮与键盘操作，拒绝不存在的日期，支持闰年。
- 年份和时分允许清空后逐字编辑；无效时间不能提交，时分失焦后补零。
- 保留受控/非受控值、外部标签、原生 FormData 和 reset，清除时回调 `null`。
- Calendar 与 TimePicker 继续使用各自的独立展示，并同步支持字符串范围限制。

## 弹层与移动端

- 日历继承 Provider 的七套配色与明暗模式，宿主可通过 `portalContainer` 与 `popoverZIndex` 放入当前模态或全屏容器。
- React Aria 统一管理嵌套弹层和焦点范围，避免父弹窗将日历设为不可交互。
- 方向键移动日期与星期，Home/End 到周首尾，PageUp/Down 切月，配合 Shift 切年；快速方向键后按 Enter 选择当前焦点日期。
- Tab 保留在日历内，Escape 关闭日历并恢复入口焦点。
- 短屏可滚动，320px 视口保持七列、每格至少 44px 的触控区域，中英文均可使用。

## 接入与验证

展示站新增日期与日期时间示例，API 元数据、Registry 源码和安装文档同步更新。CyberOS 经 `@cyberos/ui` 复用同一组件源码，并记录来源提交与文件校验和，避免宿主另写日历样式。

新增日期算法、表单和浏览器回归，覆盖主题、范围、键盘、焦点与手机布局。生产浏览器与独立 Vite/Next.js 消费者检查沿用发布工作流，三种浏览器引擎覆盖嵌套弹窗、快速键盘选择、本地日期时间提交和表单重置。

固定版本源码安装：

```sh
pnpm dlx shadcn@4.23.0 add Arasaka-Academy/CyberUI/date-picker#v0.3.0
```

```tsx
<DatePicker label="开始日期" minValue="2026-01-01" maxValue="2026-12-31" />
<DatePicker label="开始时间" includeTime defaultValue="2026-11-11T18:30" />
```
