# CyberUI v0.2.2

本版本完善组件库的表单、异步交互和可访问性契约，保留 Tailwind v4、CSS Modules、主题变量与 React 19 接入方式。GitHub Release 提供两个 `.tgz` 及 `SHA256SUMS`；组件包包含成品 CSS，消费者无需安装 Tailwind。尚未发布到 npm。

## 修复

- Select 的禁用选项同时进入选择状态与列表语义，指针和键盘均不可选中。
- MultiSelect 和 FileUpload 响应原生表单 reset：恢复非受控默认值，保留受控值，并尊重取消的 reset。FileUpload 同步原生文件、校验提示和拖动状态，支持外部表单关联变化；恢复动作等待可信原生事件的默认行为完成。
- CommandPalette 在父组件直接关闭时清空查询。
- AlertDialog 使关闭前的异步确认结果失效，避免旧操作结束后关闭后来重新打开的弹窗；底层异步操作仍由调用者管理。
- Toast 分别跟踪悬停与焦点，任一存在时暂停关闭计时；更新回调函数不再重新开始生命周期。
- Tabs、SegmentedControl 默认选中首个启用项。
- 使用外部无障碍名称的 Input 保留帮助和错误描述关联；MultiSelect 将帮助和外部描述关联到交互按钮；PasswordInput 正确应用 wrapperClassName；FileUpload 保留消费者的 aria-invalid。
- VirtualKeyboard 按完整字素退格，支持组合 emoji、旗帜和组合重音字符。
- 未初始化的 TimePicker 保持空值；Calendar 展示当前月份，不再自动选择演示日期。演示页面仍可显式传入示例值。

## 验证与发布门槛

- 新增 23 项组件回归，覆盖受控／非受控状态、原生表单、异步竞态和 Unicode 边界。
- 展示站 E2E 使用实际生产构建，检查主题、语言、响应式、键盘、焦点与 axe 自动可访问性。
- 无 Tailwind 的真实打包 Vite 消费者支持 `CYBERUI_TEST_BROWSERS=chromium,firefox,webkit`，三引擎运行同一套表单、上传、异步确认、Unicode、弹层主题与嵌套焦点检查。Next.js 成品消费者复用交互契约，并保留 Server Component 导入验证。
- Registry 继续通过真实 shadcn CLI 验证 Vite/Next.js 全部 65 个组件的源码安装和编译。
- 发布工作流只有在上述质量检查通过、四份版本号与标签一致且提交已在 main 上后，才创建 GitHub Release；Pages 另行部署。

详细验收和使用边界见 [生产可用性评估](../production-readiness.md)。浏览器自动化与 axe 扫描不等于完整 WCAG 认证或真实设备、VoiceOver 人工验收。

固定版本源码安装：

```sh
pnpm dlx shadcn@4.23.0 add Arasaka-Academy/CyberUI/button#v0.2.2
```
