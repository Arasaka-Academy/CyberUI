# CyberUI v0.2.1

本版本包含组件库、展示站与六个产品场景的 Tailwind v4 迁移，以及六项组件交互和接入修复；同时修正 pnpm 11 的发布包输出路径，确保安装包与 SHA-256 校验文件生成在同一发布目录。

## 接入变化

- Registry 源码需要 Tailwind 4.3.4：Vite 使用 `@tailwindcss/vite`，Next.js 使用 `@tailwindcss/postcss`。配置见 [源码接入指南](https://github.com/Arasaka-Academy/CyberUI/blob/v0.2.1/docs/source-installation.md)。
- 组件包包含已编译 CSS，消费者继续免安装 Tailwind。此次发布提供两个 `.tgz` 和 SHA-256 校验文件，采用 GitHub Release 分发，尚未发布到 npm。
- 保留 CSS Modules、组件 API、`--cyber-*` 变量与 React 19 接口；省略 Preflight，使用统一级联层，让工具类可以覆盖组件默认样式。
- 源码和成品 CSS 的浏览器目标为 Chrome 111+、Safari 16.4+、Firefox 128+。

固定版本源码安装：

```sh
pnpm dlx shadcn@4.23.0 add Arasaka-Academy/CyberUI/button#v0.2.1
```

## 修复

- 保留打包后 ESM 的客户端边界，支持 Next.js Server Component 直接导入组件。
- FileUpload 拖放、受控清空、格式校验与原生 FormData 保持一致，并保留输入 ref。
- 弹层挂载至 body 下独立的主题容器，避免宿主 transform 和 overflow 裁切；同步语言、配色和 CSS 变量，卸载时清理。
- CommandPalette 支持搜索框焦点下的方向键、Enter、Escape，跳过禁用命令。
- 禁用的 MultiSelect 不再向原生表单提交选中值。
- Sidebar、BottomNavigation、NavigationMenu 保留 Cmd/Ctrl/Shift/Alt 点击的浏览器行为。
- 图表在视口快速缩窄时约束尚未完成尺寸更新的绘图区，避免撑宽页面，并保留可见的键盘焦点。

## 验证与发布

发布工作流复用完整质量检查，包含类型、Lint、单元测试、Chromium E2E、无 Tailwind 的 Vite/Next.js 打包消费者，以及全部 65 个组件的 Vite/Next.js Registry 源码消费者。只有检查通过、版本与标签一致且提交已合入 main，才生成 GitHub Release。GitHub Pages 在 main 的质量检查成功后更新。
