# 视觉参考与场景映射

19 张视觉参考图保存在 `public/reference`，对应 27 个应用场景与 31 个独立预览分区。

`artifacts/reference-comparisons/index.html` 收录 31 对独立分区图片。每对左侧是参考图或参考图的一个四分区，右侧是使用公共组件组合的 Web 画布。画布为 600 × 800，保持 3:4 比例，内容超出时内部滚动；响应式模式则重排实际 HTML。

复核内容包括 Neon 背景、浅青与珊瑚红，12/8 切角及方向，2/1 边框与细线，开放角框、条码、刻度，标题与读数层级、主要区域排列和局部斜纹。颜色、字体、SVG 图标和几何使用统一的设计规则；浏览器中文字形、演示数据、封面艺术、控件最小尺寸与部分场景排列存在下面的差异。

| 编号 / 参考图 | Web 场景 | 已知差异与 Web 适配 |
| --- | --- | --- |
| 01 / `01-home.png` | `home` | 使用本地字符封面；日期、书名、阅读进度与初始装备采用固定演示数据。入口布局保留身份区、活动文件、碎片、最近书籍和启动器；窄屏重排。 |

组合图的分区顺序统一为左上、右上、左下、右下；截图选择器和分区选择器会同时更新场景、相关样式参数及参考图。对照／参考图／3:4 视图保存在 URL，刷新后可复现。

搜索、历史、回收站、阅读统计、目标、字体等场景使用同一设计系统组合实现；部分状态没有独立参考图，需结合实际交互流程检查。

所有原始配色保存在 `schemes`。`createTheme` 为普通文字、语义颜色和填充控件生成可读前景，必要时调整预览的低对比文字／表面。原始色板仍可在设计基础页查看。装饰层的裁切不缩小按钮内容、点击区域和焦点环。
